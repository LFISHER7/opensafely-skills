# Reporting rules for one output

Use this file when you write the `description` for an entry in `outputs.yaml`.

Apply the items below that match the contents of that output. Each description must stand alone.

## Checklist

- Population and data source.
- Time period
- Geography and setting
- Definitions of variables
- Name the statistical measure, such as a mean, a median, or a confidence interval. Then explain the visual/statistical symbols.
- The unit. For a percentage, name the numerator and the denominator
- The full term for every acronym/abbreviation
- Do not put result values in the description.

If any of these items are not in the repository, ask the user. Do not invent it. Do not write the file with a placeholder.
